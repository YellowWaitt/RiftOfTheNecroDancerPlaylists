# Changelog

## 0.1.2

### Fixed

- Some big issues that arise when attempting to access empty playlists :
  - Infinite screen loading.
  - Custom music menu not responding to inputs.

## 0.1.1

### Added

- The playlist category is now displayed next to the track sorter category label.
- A new name parser that attempts to extract all artists/contributors from collaborative tracks and associate them with the artists' individual playlists.
- The editor's tracks had been removed from all playlists. You can now only find them in the editor's tracks playlist.
- All missing translations to the localization file.

### Fixed

- The localization file was sometimes not found depending on how the mod archive had been extracted.

Initial release.
